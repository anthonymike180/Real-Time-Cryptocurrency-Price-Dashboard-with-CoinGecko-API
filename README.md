A live dashboard that displays real‑time cryptocurrency price data using the CoinGecko API.

## 🧩 Project Overview

This project fetches current pricing data for a selection of cryptocurrencies from the [CoinGecko API](https://www.coingecko.com/en/api) and displays it in a real‑time dashboard. The dashboard can help users monitor price changes, track trends, and visualize the market at a glance.

## 🚀 Features

- Fetches live crypto price data via CoinGecko.  
- Displays data in an easy‑to‑read dashboard layout.  
- Updates at configurable intervals for up‑to‑date pricing.  
- Clean and simple UI / code structure for easy customization.

## 🛠️ Technologies Used

- **Python** – primary scripting language.  
- [CoinGecko API](https://www.coingecko.com/en/api) – data source for cryptocurrency prices.  
- Jupyter notebook for exploratory data and visualisations.  

## ✅ Getting Started

- Clone the Repository.
- Install dependencies.
- Run the web app locally on your browser. 
- Open the notebook file in Jupyter if you’d like to explore and visualise data.

## 🔧 Configuration

- Adjust the update interval in <a href="https://github.com/anthonymike180/Real-Time-Cryptocurrency-Price-Dashboard-with-CoinGecko-API/blob/main/crypto_app.py">Web app</a> to change how often the dashboard refreshes.
- Modify the list of cryptocurrencies you want to track.
- Optionally export and store historical data in <a href="https://github.com/anthonymike180/Real-Time-Cryptocurrency-Price-Dashboard-with-CoinGecko-API/blob/main/crypto_data.csv">Dataset</a> for further analysis.

## 🎯 Use Cases

- Real‑time tracking of crypto prices for traders or enthusiasts.
- Educational tool to demonstrate API integration and dashboard creation.
- Foundation for more advanced features (alerts, analytics, custom dashboards).
